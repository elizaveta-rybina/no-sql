# Cosine Similarity

## Документация

> https://neo4j.com/docs/graph-data-science/2.23/algorithms/similarity-functions/

## Математическое описание

Cosine Similarity измеряет сходство между двумя узлами путём вычисления косинуса угла между их векторами свойств. Основная формула:

`cosine_similarity(u, v) = (u · v) / (||u|| × ||v||)`

где:

- `u · v` — скалярное произведение векторов
- `||u||` и `||v||` — евклидовы нормы векторов

Результат находится в диапазоне от 0 до 1:

- 1 означает полное сходство (идентичные векторы)
- 0 означает отсутствие сходства (ортогональные векторы)

Алгоритм особенно полезен для сравнения узлов на основе их численных характеристик или членства в категориях. В графах знаний и сетях рекомендаций Cosine Similarity позволяет найти узлы с похожими "профилями" или "интересами".

## Пример использования

### Документация

```cypher
MATCH (n) DETACH DELETE n;

CREATE (a:Movie {name: "Action Movie A", budget: 100, rating: 8.5, viewers: 1000}),
       (b:Movie {name: "Action Movie B", budget: 95, rating: 8.3, viewers: 950}),
       (c:Movie {name: "Drama Movie C", budget: 50, rating: 7.5, viewers: 500}),
       (d:Movie {name: "Drama Movie D", budget: 55, rating: 7.6, viewers: 520}),
       (e:Movie {name: "Comedy Movie E", budget: 30, rating: 6.8, viewers: 300});
```

```cypher
CALL gds.graph.drop('myGraph', false) YIELD graphName;

CALL gds.graph.project(
  'myGraph',
  'Movie',
  'DUMMY'
)
YIELD graphName, nodeCount;
```

```cypher
MATCH (a:Movie {name: "Action Movie A"}), (b:Movie {name: "Action Movie B"})
CALL gds.similarity.cosine.stream('myGraph', {
    nodeProperties: ['budget', 'rating', 'viewers'],
    sourceNode: a,
    targetNode: b
})
YIELD similarity
RETURN similarity
```

```cypher
MATCH (a:Movie {name: "Action Movie A"}), (c:Movie {name: "Drama Movie C"})
CALL gds.similarity.cosine.stream('myGraph', {
    nodeProperties: ['budget', 'rating', 'viewers'],
    sourceNode: a,
    targetNode: c
})
YIELD similarity
RETURN similarity
```

## Практическая значимость

Cosine Similarity широко используется в системах рекомендаций для поиска похожих товаров, фильмов, музыки или статей. В e-commerce платформах алгоритм помогает предложить пользователю товары с похожими характеристиками (цена, размер, бренд) на просмотренные. В потоковых сервисах (Netflix, YouTube) Cosine Similarity используется для рекомендации контента, похожего по жанрам, рейтингам и популярности. В системах классификации текстов алгоритм применяется для определения семантического сходства между документами. В биоинформатике Cosine Similarity помогает находить гены или белки с похожими функциями на основе их профилей экспрессии. Простота реализации и эффективность вычислений делают этот алгоритм одним из самых популярных в машинном обучении и анализе данных.

## Дополнительные минимальные примеры использования

### Идентичные узлы (сходство = 1)

```cypher
// 1. Два узла с идентичными свойствами
MATCH (n) DETACH DELETE n;
CREATE (a:Product {name:'Product A', price: 100, rating: 4.5, stock: 50}),
       (b:Product {name:'Product B', price: 100, rating: 4.5, stock: 50});
```

```cypher
// 2. Проекция графа
CALL gds.graph.drop('myGraph', false) YIELD graphName;
CALL gds.graph.project(
  'myGraph',
  'Product',
  'DUMMY'
)
YIELD graphName;
```

```cypher
// 3. Запуск: идентичные векторы
// Ожидаемый вывод: similarity = 1.0
MATCH (a:Product {name:'Product A'}), (b:Product {name:'Product B'})
CALL gds.similarity.cosine.stream('myGraph', {
    nodeProperties: ['price', 'rating', 'stock'],
    sourceNode: a,
    targetNode: b
})
YIELD similarity
RETURN similarity;
```

### Сравнение всех пар узлов

```cypher
// 1. Несколько продуктов для сравнения
MATCH (n) DETACH DELETE n;
CREATE (a:Product {name:'Laptop', price: 1000, weight: 2.0, battery: 10}),
       (b:Product {name:'Phone', price: 800, weight: 0.2, battery: 24}),
       (c:Product {name:'Tablet', price: 500, weight: 0.5, battery: 12});
```

```cypher
// 2. Проекция графа
CALL gds.graph.drop('myGraph', false) YIELD graphName;
CALL gds.graph.project(
  'myGraph',
  'Product',
  'DUMMY'
)
YIELD graphName;
```

```cypher
// 3. Вычисление сходства для всех пар
// Ожидаемый вывод: 3 строки с попарными сравнениями
MATCH (a:Product), (b:Product) WHERE a.name < b.name
CALL gds.similarity.cosine.stream('myGraph', {
    nodeProperties: ['price', 'weight', 'battery'],
    sourceNode: a,
    targetNode: b
})
YIELD similarity
RETURN a.name, b.name, similarity
ORDER BY similarity DESC;
```
